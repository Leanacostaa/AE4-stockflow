Catálogo de productos

Datos de la vista vw_CatalogoProductos: precio vigente (historial de precios) y stock total (suma por depósito).

Existencias por depósito

Tabla Stock (relación N:M entre Producto y Depósito). Las cantidades solo cambian mediante movimientos de kardex: el trigger trg_MovimientoStock_AplicarKardex las actualiza y trg_Stock_ControlarExistencias controla la capacidad máxima.

Registrar venta

Ejecuta dbo.sp_RegistrarPedido: pedido, renglones con precio vigente y egreso de stock en una única transacción.

Renglones (desde el carrito)
Llamada T-SQL que envía la aplicación 
DECLARE @PedidoId INT, @NroPedido NVARCHAR(16);
EXEC dbo.sp_RegistrarPedido
     @ClienteId = ?, @EmpleadoId = ?, @SucursalId = ?,
     @DepositoId = ?, @Canal = ?, @NroDireccion = ?,
     @ItemsJson = ?,   -- [{"ProductoId":6,"Cantidad":2}]
     @PedidoId  = @PedidoId  OUTPUT,
     @NroPedido = @NroPedido OUTPUT;
-- Dentro del SP: BEGIN TRANSACTION ... COMMIT,
-- o ROLLBACK + THROW si falla cualquier control.
Salida del servidor
> SQL Server listo. Agregue productos al carrito y ejecute el procedimiento.
